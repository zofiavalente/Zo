# Desculpa, meu amor 🥺💕

Um pequeno site de pedido de desculpas, cheio de gatos e corações.

- **Fotos:** coloca-as na pasta `fotos/` como `foto1.jpg`, `foto2.jpg`, …
- **Nome dele:** altera `NOME_DELE` no início de `script.js`.
- **Texto da carta:** edita a secção `carta` em `index.html`.

Para o pôr online: no GitHub, *Settings → Pages → Deploy from a branch*, escolhe este ramo e a pasta `/ (root)`.
